## 🚀 Featured Projects

**[Real-Time Food Delivery Data Pipeline](https://github.com)** — `Azure Service Bus` `Azure Databricks` `Unity Catalog` `PySpark` `Delta Lake` `Power BI`<br><br>- Built a real-time pipeline streaming order events from Python through Azure Service Bus into a Databricks Delta Lake Medallion architecture (Bronze → Silver → Gold) using Spark Structured Streaming, watermark-based deduplication, and foreachBatch; governed with Unity Catalog.<br>- Designed a star schema and implemented SCD Type 2 using Delta Lake MERGE to preserve historical customer records and support CDC-style tracking.<br>- Resolved checkpoint reprocessing, schema drift, and streaming join issues; delivered Gold-layer insights through a live Power BI DirectQuery dashboard.
